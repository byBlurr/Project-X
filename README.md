# Breach Protocol

A top-down 2D WWII-era zombie survival game built with Godot 4.7.1 and C#. Hold your position. Survive the horde.

## Overview

Breach Protocol is an indie zombie survival game set in a gritty alternate WWII timeline. Playing as a resourceful British soldier, you must defend fortified positions against waves of relentless Nazi zombies. Board up windows, secure doors, and scavenge for weapons as the undead breach deeper into your sanctuary.

## Features

- **Strategic Defense**: Blockade entry points to slow the zombie advance
- **Dynamic Combat**: Start with a pistol and discover better weapons scattered throughout each map
- **Environmental Gameplay**: Exploit the map layout to your tactical advantage
- **Advanced Physics**: Inertia-based movement and realistic bullet ballistics (planned)
- **Wave-Based Progression**: Increasingly challenging zombie spawns test your survival skills
- **Atmospheric Setting**: Dark WWII-inspired aesthetics and immersive audio design

## Gameplay

1. **Survive Waves**: Zombies breach windows and doors in escalating waves
2. **Scavenge Weapons**: Explore maps to find rifles, grenades, and other armaments
3. **Fortify Position**: Build and maintain barricades to control zombie entry points
4. **Escape or Endure**: Survive until extraction or make a final stand

## Technical Details

- **Engine**: Godot 4.7.1
- **Language**: C#
- **Platform**: Windows/Linux/macOS (planned console support)
- **Graphics**: 2D Top-Down Perspective
